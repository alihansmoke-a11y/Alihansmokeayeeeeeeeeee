# Легендарная Барселона | Més que un club

Информационный сайт, посвящённый футбольному клубу «Барселона»: история, легенды, состав, матчи, трофеи.

## Назначение

Объединить актуальную информацию о клубе в одном месте:
- история клуба с 1899 года;
- легенды клуба (Месси, Роналдиньо, Кройф);
- текущий состав сезона 2026/27 (загружается динамически);
- матчи, результаты и статистика;
- коллекция трофеев.

## Состав проекта

| Файл / папка | Назначение |
|--------------|------------|
| `index.html` | Главная страница |
| `players.html` | Легенды клуба |
| `current-squad.html` | Текущий состав |
| `matches.html` | Матчи |
| `history.html` | История |
| `trophies.html` | Трофеи |
| `players/` | Профили игроков |
| `css/style.css` | Стили |
| `js/main.js` | Общая логика (анимации) |
| `js/squad-loader.js` | Загрузка состава |
| `data/squad.js` | Данные состава |
| `src/models/` | Классы предметной области |
| `src/storage/` | Класс хранилища |
| `src/services/` | Класс-сервис |
| `docs/` | Документация |
