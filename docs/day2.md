# День 2. Классы и архитектура

## Классы предметной области

### `Player` (src/models/Player.js)
Хранит данные игрока: номер, ФИО, возраст, гражданство, позиция, рост, вес, статистика.
Метод: `getShortInfo()` — краткая строка для карточки.

### `Match` (src/models/Match.js)
Хранит данные матча: дата, турнир, соперник, счёт, события.
Метод: `getResult()` — возвращает 'W', 'D' или 'L'.

### `Squad` (src/models/Squad.js)
Хранит коллекцию игроков по категориям.
Метод: `getByPosition(position)` — фильтрация.

## Класс хранилища

### `SquadStorage` (src/storage/SquadStorage.js)
Загружает данные из `data/squad.js` и отдаёт их сервису.

## Класс-сервис

### `SquadService` (src/services/SquadService.js)
Связывает модель и хранилище: получает данные, формирует объекты, фильтрует.
