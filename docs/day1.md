# День 1. Постановка задачи

## Идея проекта
Сайт о футбольном клубе «Барселона»: история, легенды, состав, матчи, трофеи.

## Основные сущности
- **Игрок** — номер, ФИО, возраст, гражданство, позиция, статистика.
- **Матч** — дата, соперник, счёт, турнир, хронология событий.
- **Состав** — коллекция игроков по категориям.
- **Трофей** — название, количество, годы.

## Сценарии
1. Просмотр состава с фильтрацией по позициям.
2. Клик по игроку → открытие модального окна с биографией.
3. Просмотр матчей с фильтрацией по турнирам.
4. Просмотр трофеев по категориям.
